# 무전공으로 성공을 잡다 — 학생 성공을 위한 전략과 비전

> 2025 빅데이터 분석 경진대회 · 팀 JJ 피크민's · 2025.11

## 개요
무학과·무전공 제도 도입을 앞두고 학생들이 생각하는 "학생 성공"이 무엇인지, 그리고 교양 교육과정이 어떻게 바뀌어 왔는지를 데이터로 분석해 학생 지원 방향을 제안했습니다.

## 분석 내용
- **학생 인식 분석**: 학생성공 설문(2022~2024) 자유응답 텍스트 → 워드클라우드, 응답 유형 비율 (예: '취업' 42.2%)
- **교양 교과 트렌드 분석**: 학년도별 교양 교과 개설 수, 이수구분(교필/교선 등) 비율 변화, 교과 설명 TF-IDF 키워드 추이
- **IT·AI 교양 과목 분류**: 전체 교양 교과 중 IT/AI 관련 과목 추출 및 유지 과목 분석
- **STRONG 직업흥미검사** 결과와 연계한 진로 지원 방향 제안

## 구조
```
analysis/
├─ gyeoyang_trend_analysis.ipynb     # 교양 교과 학년도별 트렌드 분석
├─ gyeoyang_optionA_no_tfidf.ipynb   # 키워드 기반 분석 (TF-IDF 미사용 버전)
├─ test1.py ~ test4.py               # 시각화·집계 스크립트
└─ new_xlsx.py                       # 분석 결과 엑셀 정리
results/                             # 분석 결과 엑셀, 시각화 이미지
```

## 기술
Python · pandas · matplotlib · scikit-learn(TF-IDF) · WordCloud · Excel

## 내 역할
데이터 전처리와 교양 교과 트렌드 분석 코드 작성, 시각화 결과 정리
